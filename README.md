# 국내증시 전체 스캐너 (KR Stock Confluence Scanner)

코스피·코스닥 **전종목**을 자동 스캔해서, 6레이어 컨플루언스 매수 조건을 만족하는 종목을 **텔레그램으로 알림**합니다.

## 설계 — 똑똑한 깔때기(Funnel)

전체 2,800종목을 무식하게 다 돌리지 않습니다. 매수 신호는 거래량·모멘텀 동반 시에만 뜨므로, "지금 움직이는" 종목만 추려서 정밀 계산합니다.

```
1단계  KIS 순위 API 3콜 (거래증가율 / 거래대금 / 상승률 Top30)
         ↓  합집합 ≈ 60~100종목 (우선주/ETF/스팩 제외)
2단계  후보만 일봉 가져와 6레이어 컨플루언스 계산
         ↓  5/6 이상
3단계  텔레그램 푸시 (손절/익절 포함)
```

→ 한 바퀴 호출 약 85회 / 10초. API 차단 없이 전체 시장 커버.

## 6레이어 컨플루언스 (일봉 / EMA 5·20·60)

| 레이어 | 조건 |
|--------|------|
| L1 | 3EMA 정배열 (5>20>60) |
| L2 | 장기추세 상승 (60일선 위) |
| L3 | 피보 황금구간 또는 20일선 지지 |
| L4 | RSI 45 상향돌파 또는 MACD 골든크로스 |
| L5 | 거래량 급증(1.5x) + 양봉 |
| L6 | 20일 신고가 돌파 (BOS) |

## 환경변수 (Railway Variables)

| 변수 | 설명 |
|------|------|
| `KIS_APP_KEY` | 한국투자증권 앱키 |
| `KIS_APP_SECRET` | 한국투자증권 앱시크릿 |
| `TELEGRAM_TOKEN` | 텔레그램 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 텔레그램 챗 ID |
| `THRESHOLD` | 알림 점수 (기본 5, 6=최상위만) |
| `RATE_PER_SEC` | 초당 API 호출 상한 (앱키 공유시 낮추기) |
| `SCAN_INTERVAL` | 스캔 주기 초 (기본 600=10분) |
| `FINAL_SCAN` | 마감확정 스캔 시각 (기본 1512) |

## 실행

```
pip install -r requirements.txt
python main.py
```

## 주의

- KIS는 앱키당 **초당 20건** 제한. 다른 봇과 공유 시 `RATE_PER_SEC`를 낮추세요.
- 일봉 신호는 장중엔 잠정, 15:30 마감 후 확정.
- KIS 순위 API의 `FID_*` 파라미터는 계정/문서 버전에 따라 다를 수 있어 검증 필요.

> ⚠️ 투자 판단의 참고용 보조도구이며, 매매 책임은 본인에게 있습니다.
